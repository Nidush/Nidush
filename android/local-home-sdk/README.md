Place the official Google Home Android SDK files in this folder after downloading them from Google Home Developers.

Suggested workflow:

1. Sign in at https://developers.home.google.com/apis/android/sdk
2. Download the Android SDK package
3. Extract it inside `android/local-home-sdk/`
4. Update the Gradle dependency coordinates once you know the exact artifact names shipped by Google

Do not commit large vendor SDK binaries unless your team explicitly wants them versioned.
